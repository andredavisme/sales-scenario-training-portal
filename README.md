# Sales Scenario Training Portal

An open-source educational template showing developers how to build an **interactive, scenario-based sales training tool** — backed by Supabase and hosted on GitHub Pages.

This repo uses a **fictitious company and product line** (Meridian Industrial Supply / VoltEdge product series) as the working example, so the full build process can be taught publicly without exposing proprietary data.

## Two Deliverables

| Deliverable | Audience | Stack | Format |
|---|---|---|---|
| **Public Educational Template** | Developers learning the pattern | Supabase + GitHub Pages | Live hosted web app |
| **Internal Handoff Build** | End-user / sales team | Vanilla HTML/CSS/JS, embedded data | Self-contained `.zip`, runs in browser |

## Docs

- [`docs/progress.md`](docs/progress.md) — milestones and current status
- [`docs/training-build-guide.md`](docs/training-build-guide.md) — student-friendly walkthrough of how the app is built

## Quick Start (Public Template)

1. Fork this repo
2. Connect your own Supabase project (see build guide)
3. Seed with your own scenario data
4. Enable GitHub Pages on `main`

## Quick Start (Internal Zip)

1. Download the latest `.zip` from [Releases](../../releases)
2. Unzip and open `index.html` in any browser
3. No internet connection or server required
